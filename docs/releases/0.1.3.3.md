# Create: Give Me FPS 0.1.3.3 — восстановление 0.1.3 и экспериментальные порты

**Предварительный выпуск / Pre-release.** Основная сборка восстанавливает
поведение 0.1.3. Добавленные порты для других версий Minecraft экспериментальные;
их нельзя считать полностью проверенными или одинаковыми по возможностям.

## Какой файл скачать

| Minecraft | Загрузчик | Файл |
| --- | --- | --- |
| 1.21.1 | NeoForge | `create_gmf-0.1.3.3.jar` |
| 1.20.1 | Forge / NeoForge | `create_gmf-0.1.3.3-mc1.20.1-forge-neoforge.jar` |
| 1.20.1 | Fabric / Quilt | `create_gmf-0.1.3.3-mc1.20.1-fabric-quilt.jar` |
| 1.19.2 | Forge | `create_gmf-0.1.3.3-mc1.19.2-forge.jar` |
| 1.19.2 | Fabric / Quilt | `create_gmf-0.1.3.3-mc1.19.2-fabric-quilt.jar` |
| 1.18.2 | Forge | `create_gmf-0.1.3.3-mc1.18.2-forge.jar` |
| 1.18.2 | Fabric / Quilt | `create_gmf-0.1.3.3-mc1.18.2-fabric-quilt.jar` |

Устанавливайте **один** JAR для своей версии игры и загрузчика, а не все сразу.
Entity Culling обязателен на клиенте. Для Fabric нужен Fabric API; настройки
открываются через Mod Menu. У старых портов Java 17, у 1.21.1 — Java 21.
Точные версии Create и зависимости указаны в [матрице портов](../../ports/README.md).

## Новое в мультиверсионных сборках

- Подготовлены шесть отдельных портов дополнительно к основной 1.21.1 NeoForge.
- Для 1.20.1 адаптированы Flywheel 1.0.5, регистрация клиента, конфигурация,
  интерфейс, перехваты жидкостей и настоящая точка обновления визуалов Storage.
- Для Create 0.5.1 / Flywheel 0.6 добавлены отдельные адаптеры данных вращения
  и прокрутки лент, кадровых/тиковых обновлений, видимости блоков и старого GUI.
- Исправлены отличия старого API: пакеты AnimationTickHolder/LerpedFloat,
  метод угла кинетики, отрисовка теней лент, события клиента и текстовые компоненты.
- Владение данными старого Flywheel отслеживается на протяжении конструктора
  **и init()** с обязательным освобождением контекста при исключении.
- Исправлено преобразование ссылок в аннотациях mixin для готовых JAR:
  Fabric intermediary и Forge SRG, включая вызов диспетчера Entity Culling.
- MixinExtras встроен в JAR; лицензии и упоминания стороннего кода сохранены.
- Добавлены воспроизводимые сценарии сборки, проверки бинарных точек подключения,
  метаданных, Java bytecode, локализаций и SHA-256 каждого файла.

### Ограничения портов — важно

- В 1.18.2/1.19.2 **нет ускоренного буферного рендера CreateBetterFPS**.
  Вместо неработающего переключателя показано объяснение.
- Полный перенос анимаций актёров и движущихся конструкций на старый Flywheel
  **ещё не завершён**. Не считать старые порты полноценной заменой основной сборки.
- Quilt и NeoForge 1.20.1 отдельно не проверялись. Для остальных новых портов
  проверен запуск dev-клиента, но не готового production-JAR в пользовательской сборке.
- Не проверены огромный завод, фактический прирост FPS, полная матрица
  шейдеров/аддонов и восстановление всех механизмов после возвращения издалека.
- В тестовом окружении Forge 1.18.2 потребовался параметр системного аллокатора
  LWJGL; он не встраивается в мод. В Fabric 1.18.2 найдено нефатальное сообщение
  встроенного Forge Config API Port 3.2.4 о его отсутствующем Mod Menu entrypoint.
- Пройдено 22 теста основной сборки и по 18 для каждого нового порта:
  **130 запусков тестов суммарно**, включая повторяющиеся общие проверки.
  Это **не** число исправленных багов и не доказательство игрового поведения.

## Основная сборка 1.21.1: восстановление поведения

Основа исходников: опубликованный 0.1.3, commit
`4d2d8485dca16c9c129b0bedbbbd0797d6965f29`.
Не надстройка над 0.1.3.2: её переписанный контроллер владения визуалами не используется.

## Что возвращено относительно 0.1.3.2

- При дальности 0 либо выключенной группе анимации остаются статичными.
  Отсутствие позиции/камеры не переопределяет явное отключение.
- Сохранён резервный перехват незарегистрированных ScrollInstance, не только лент.
- Возвращены прежние фильтры ванильных эффектов воды/лавы, используемых Create,
  блокировка эффекта заполнения/слива и остановка текстур жидкости.
- Сохранено поведение 0.1.3 для целого плана визуального обновления конструкций,
  а также обновление визуалов после перемещения через границу дальности.
- Профили, группы механизмов, интерфейс и диагностика взяты из 0.1.3.
  Новые экспериментальные функции 0.1.3.2 в эту восстановительную сборку не перенесены.

## Точечные исправления поверх 0.1.3

- Убрано некорректное объявление унаследованного поля entity в mixin конструкций.
  Условие остановки самого плана не изменено.
- Поддержаны старый и новый пути Cullable API Entity Culling; добавлен адаптер
  prefetched-снимков для новых Entity Culling. При Nowheel пересекающиеся адаптеры отключаются.
- Изменения видимости из фонового потока передаются в клиентский поток.
- Выключенный GMF больше не скрывает предметы ленты только из-за сохранённого тумблера.
  При включённом GMF правила показа предметов остаются как в 0.1.3.
- Схема конфигурации остаётся 13 для чтения настроек из 0.1.3.2 без сброса профиля.
- Добавлены регрессионные проверки отключений, неизвестной позиции, прокрутки,
  сохранения перехватов 0.1.3 и совместимости зависимостей.

## Ограничения

Это восстановление известного поведения, не заявление об исправлении всех старых ошибок.
В частности, сохранённые широкие фильтры частиц и общие текстуры воды/лавы могут влиять
и на ванильные эффекты, а отключение предметов около дробилок остаётся как в 0.1.3.
Это сознательно не маскируется под новую адресную систему фильтрации.

Сборка и автоматические проверки не заменяют испытание исходного мира пользователя.
Ручной тест механизмов, точное сравнение FPS с 0.1.3, полная матрица шейдеров/аддонов
и возвращение с дальней дистанции: **NOT VERIFIED**, пока не пройдены в игре.

Проверено локально: чистая сборка, 22 теста (5 наборов, без ошибок/пропусков),
313 совпадающих RU/EN ключей. Отдельный dev-клиент с Create 6.0.10 и Entity Culling
1.11.2 загрузил ресурсы, атласы и 77 исходников шейдеров Flywheel без ERROR/FATAL
в журнале. Затем тестовый процесс остановлен; миры пользователя не открывались.
Это проверка загрузки, а не проверка анимаций на фабрике.

Совместимость: Minecraft 1.21.1, NeoForge 21.1.219+, Create 6.0.10,
Flywheel 1.0.6, Java 21. Entity Culling обязателен на клиенте.
Заменять старый GMF следует одним `create_gmf-0.1.3.3.jar`, не оставляя две версии.
После перехода с 0.1.3.2 заново выберите нужный профиль, если хотите применить
весь набор его значений из 0.1.3; пользовательские настройки автоматически не сбрасываются.
