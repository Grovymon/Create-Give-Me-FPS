# Create: Give Me FPS

[English](README.md) · [Скачать релизы](https://github.com/Grovymon/Create-Give-Me-FPS/releases) · [Технический отчёт](docs/AUDIT_REPORT.md)

<p align="center"><img src="docs/icon.png" alt="Create: Give Me FPS" width="240"></p>

GMF — **клиентский мод управления визуальной нагрузкой и диагностики фабрик Create**.
Мод не меняет реальные тики, RPM, stress, рецепты, инвентари, жидкости, транспорт предметов,
редстоун, поезда, физику движущихся конструкций и сохранения мира.
Отключение изображения не останавливает фабрику.

## Что можно настроить

Откройте настройки через меню модов Minecraft. Профили: Картошка, Низкий, Средний,
Выше среднего, Высокий, Ультра и Пользовательский. Настройки охватывают поддерживаемые
пути отрисовки; обещания поддержки любого стороннего рендера нет.

- **Механизмы:** отдельные группы анимаций, дальность полных анимаций 0–32 блока,
  поведение вдали (полное/упрощённое/статичное), частота упрощённых анимаций,
  делитель тиков только клиентских Visual.
- **Останавливать анимации вне поля зрения:** отдельная настройка, не скрытие за стеной.
  Использует frustum камеры, кешированные расширенные границы и три кадра ожидания у края.
  По умолчанию выключена до проверки игровой матрицы. Неизвестные границы считаются видимыми.
  При возвращении в камеру анимация возобновляется без ожидания следующего редкого обновления.
- **Скрывать закрытые механизмы:** Entity Culling передаёт состояние видимости;
  GMF управляет восстановлением Flywheel Visual. Если установлен Nowheel, GMF уступает ему эту систему.
  Движущиеся конструкции за стенами не скрываются.
- **Аддоны Create:** Механизмы → Аддоны Create → установленный аддон →
  обнаруженные совместимые типы механизмов. Классификация по реестру/типу и наследованию Create.
  Жёстких зависимостей на аддоны нет; собственные рендеры требуют отдельных адаптеров и тестов.
- **Ленты:** полное скрытие перевозимых стаков и отдельное управление их тенями.
  Выброшенные предметы, в том числе рядом с дробилками и после катапульты, не скрываются по близости.
- **Частицы:** полный/сокращённый/выключенный режим, категории пара/дыма, искр,
  разрушения предметов и жидкостей. Общий фильтр принимает только частицы реестра Create.
  Проверенные клиентские вызовы FluidFX и горелки могут отключать их ванильные эффекты.
  Посторонние ванильные частицы глобально не подавляются.
- **Flywheel:** Авто, Непрямая, Инстансинг, Выключен. Ускоренный рендер на основе
  CreateBetterFPS требует Sodium и Iris. Оба параметра рендера применяются при запуске:
  красное предупреждение исчезает при возврате сохранённых значений к активным.
- **Режим производительности:** назначьте отдельную, изначально свободную клавишу
  в управлении Minecraft. Текущие визуальные настройки → Картошка → точное восстановление
  предыдущих значений, включая пользовательские. Временная Картошка не сохраняется
  случайно при изменении настроек логирования.
- **Адаптивные рекомендации:** включаемые отдельно предложения при устойчивом
  изменении FPS, с задержками и cooldown. Настройки автоматически не меняются.

## Диагностика

Режим разработчика записывает локальные отчёты в `logs/GMF/<дата-время>/`:
запуск записи, отдельный снимок, остановка с сохранением. Телеметрии и отправки данных нет.

Измеряются интервалы кадров, средний FPS, 1% low при достаточной выборке, p95/p99,
максимум времени кадра, память и GC; MSPT доступен только там, где собирается.
Количество ближайших объектов — оценка, причина нагрузки — вывод по правилам,
а не измеренное время каждого механизма.

Добавлены наблюдаемые счётчики видимых/внекамерных/закрытых Visual, количества
Flywheel Visual блоков, пропущенных/возобновлённых обновлений, аддонов,
вызовов отрисовки предметов лент и подавленных запросов частиц/эффектов.
Пропуск одного FluidFX-вызова не означает измеренное число отдельных частиц.

После диагностики доступны несколько рекомендаций с подтверждением применения.
A/B позволяет выбрать тени, occlusion, анимации за камерой, дальние анимации,
предметы лент или частицы. Flywheel и ускоренный рендер сравниваются только
в отдельных запусках после перезапуска, без выдуманных live-результатов.

## Установка и требования

Minecraft **1.21.1**, Java **21**, NeoForge **21.1.x**, Create **6.0.10**, Flywheel **1.0.6**.
Entity Culling обязателен **на клиенте**. Серверу GMF не требуется.
[Матрица совместимости](docs/COMPATIBILITY.md) разделяет сборку, startup и игровые тесты.

Скачайте подходящий NeoForge JAR из [релизов](https://github.com/Grovymon/Create-Give-Me-FPS/releases),
поместите в `mods` сборки и уберите дубли старых версий GMF.

## Разработка и ограничения

```powershell
.\gradlew.bat clean test build
.\gradlew.bat runClient
```

JAR собирается в `build/libs/`. Dev-зависимость Entity Culling выбирается по
однозначному NeoForge version ID и не включается внутрь GMF.
[Архитектура](docs/ARCHITECTURE.md) · [Профайлер](docs/PROFILER.md) ·
[A/B](docs/BENCHMARK.md) · [Следующий этап](docs/FUTURE_WORK.md).

Нет гарантированного процента FPS, GPU-времени каждого механизма, батчинга моделей
предметов, профилей по измерению и скрытия движущихся конструкций за стеной.
Успешная сборка и startup не заменяют тесты восстановления анимаций в мире и с шейдерами.
