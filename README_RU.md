# Create: Give Me FPS

Русский | [English version](README.md)

<p align="center">
  <img src="docs/icon.png" alt="Значок Create: Give Me FPS" width="360">
</p>

**Create: Give Me FPS** — клиентский мод оптимизации и диагностики для больших
фабрик из **Create**. Он даёт игроку управление тяжёлыми визуальными эффектами:
анимациями механизмов, предметами на лентах, частицами и рендером Flywheel —
без изменения самой фабрики.

Целевая платформа: **Minecraft Java 1.21.1 · NeoForge · Create 6.0.10 ·
Flywheel 1.0.6 · Java 21**.

> Мод меняет только изображение на клиенте. Рецепты, инвентари, нагрузка
> stress-сетей, работа механизмов, сохранения мира и серверная симуляция не
> изменяются.

## Что умеет мод

Откройте экран настройки мода через меню модов Minecraft. Можно выбрать готовый
графический профиль либо настроить отдельные визуальные системы. Все настройки
сохраняются локально у игрока.

### Графические профили

Шесть профилей дают быструю стартовую настройку:

| Профиль | Для чего подходит |
| --- | --- |
| Картошка | Максимальный FPS: тяжёлые эффекты выключаются или сильно упрощаются. |
| Низкий | Слабый ПК или очень большая фабрика. |
| Средний | Сбалансированная повседневная настройка. |
| Выше среднего | Больше деталей при умеренных ограничениях. |
| Высокий | Приоритет качеству для обычного мира Create. |
| Ультра | Почти без уменьшения визуальных эффектов. |

Профиль можно менять в любой момент. После ручного изменения выбранного
параметра профиль становится «Пользовательским», поэтому настройка не будет
молча потеряна.

### Анимации механизмов

Большое количество валов, шестерён, лент, движущихся частей и кинетических
блоков может заметно нагружать клиент. Доступны:

- общий переключатель поддерживаемых анимаций Create;
- отдельное меню **«Отдельные механизмы»** с поиском и группами: валы/шестерни,
  ленты, маховики, рукоятки, дробильные колёса, вентиляторы, конструкции и
  поддерживаемые обрабатывающие механизмы;
- дальность полных анимаций от **0 до 32 блоков** — `0` означает, что полная
  анимация не рисуется нигде;
- поведение дальних анимаций: оставить, упростить или оставить неподвижными;
- частота обновления упрощённой дальней анимации.

Механизмы продолжают работать. Настройки меняют только поддерживаемые пути
обновления и рисования на клиенте.

### Ленты и предметы

Крупные линии сортировки могут нагружать рендер даже без теней. В настройках
лент можно отдельно управлять:

- предметами, движущимися по поддерживаемым конвейерам;
- тенями предметов на лентах;
- выпавшими предметами около дробильных колёс;
- оптимизацией дальних теней предметов.

Это особенно полезно для сортировок и массовой обработки, где одновременно
видны тысячи предметов.

### Частицы и эффекты жидкостей

Раздел «Частицы» управляет выбранными визуальными эффектами Create и жидкостей:

- режим частиц Create: полные, уменьшенные или выключенные;
- отдельные ограничения пара/дыма, искр, эффектов разрушения предметов и
  блоков, а также всплесков воды и лавы;
- прямое подавление поддерживаемых путей эффектов жидкости Create, включая
  эффекты шланговых механизмов.

Эти настройки не меняют передачу жидкости и логику механизма. Часть эффектов
может создаваться ванильным Minecraft, сторонним модом или ещё не
поддерживаемым путём Create; в таких случаях мод показывает это в отчёте, а не
обещает отключить все частицы без исключений.

### Flywheel и шейдеры

Страница Flywheel даёт доступ к выбору рендера, который обычно скрыт в конфиге:

- **По умолчанию** — стандартный выбор Create/Flywheel;
- **Непрямая отрисовка** — indirect-путь Flywheel;
- **Инстансинг** — отрисовка экземпляров там, где она совместима;
- **Выключен** — отключение интеграции рендера Flywheel;
- **Ускоренный рендер** — необязательная оптимизация, адаптированная из
  [CreateBetterFPS](https://github.com/MoePus/CreateBetterFPS), когда
  одновременно установлены Sodium и Iris.

После смены рендера Flywheel или «Ускоренного рендера» необходим **полный
перезапуск игры**. Меню показывает это требование, когда сохранённый выбор
отличается от рендера, активного в текущем запуске.

### Режим разработчика и локальные отчёты

Режим разработчика помогает проверять именно место, где падает FPS, а не
угадывать причину по меню паузы. Он содержит:

- **«Запустить запись»** — сразу создаёт сессию отчёта с датой и временем;
- **«Сохранить отчёт»** — пишет снимок текущего состояния;
- **«Остановить и сохранить»** — сохраняет итоговый снимок и завершает запись;
- необязательное автоматическое сохранение при скачках времени кадра;
- подсчёт объектов Create рядом: block entities, кинетических блоков, лент,
  цепных конвейеров, конструкций и типовых семейств механизмов;
- данные о времени кадра, FPS, 1% low, частицах и обнаруженных путях рендера.

Отчёты находятся только на компьютере игрока в
`logs/GMF/<дата-время>/`. Это не телеметрия: мод ничего не отправляет в сеть.
Подсчёт сцены помогает выбрать направление проверки, но не заменяет полный
CPU/GPU-профайлер.

## Требования

| Компонент | Нужная версия |
| --- | --- |
| Minecraft | 1.21.1 |
| Загрузчик | NeoForge 21.1.x |
| Create | 6.0.10 |
| Flywheel | 1.0.6 |
| Java | 21 |

Мод клиентский: на сервер устанавливать его не требуется. При этом версии всех
модов в сборке должны оставаться совместимыми между собой.

## Установка

1. Установите NeoForge, Create и Flywheel для Minecraft 1.21.1.
2. Скачайте `Create-Give-Me-FPS-0.1.2-NeoForge-1.21.1.jar` на странице
   [Releases](../../releases).
3. Поместите JAR в папку `mods` нужного экземпляра игры.
4. Откройте меню модов Minecraft и выберите **Create: Give Me FPS** для
   настройки клиента.

## Важные ограничения

- Мод не добавляет низкополигональные модели Create, LOD-ландшафт или текстуры
  меньшего разрешения.
- Create, Flywheel, шейдеры и аддоны используют разные пути рендера. Отключение
  поддерживаемой группы уменьшает покрываемую нагрузку, но не гарантирует, что
  исчезнет сторонний эффект.
- FPS корректно сравнивать только из одной точки, с тем же направлением камеры,
  дальностью прорисовки, разрешением, шейдером и состоянием фабрики.
- Если другой мод управляет той же функцией Create/Flywheel, не включайте
  дублирующие оптимизации одновременно.

## Сборка из исходников

```powershell
.\gradlew.bat clean test build
```

JAR для разработки создаётся в `build/libs/`.
