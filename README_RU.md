**Текущая версия: 0.1.4**

> **Новое в 0.1.4:** добавлен необязательный ускоренный рендер Create,
> адаптированный из CreateBetterFPS MoePus по лицензии MIT.

Клиентский мод оптимизации и внутриигровой диагностики для **Minecraft Java
Edition 1.21.1**, **NeoForge**, **Create 6.0.10** и **Flywheel 1.0.6**.

Create: Give Me FPS уменьшает лишнюю нагрузку от рендеринга крупных заводов
Create, не останавливая работу механизмов, инвентарей, рецептов, силовых сетей и
серверной симуляции.

## Возможности

- шесть профилей графики: Картошка, Низкий, Средний, Выше среднего, Высокий и Ультра;
- поиск и отдельное управление анимациями 20 групп механизмов Create;
- полные, пониженные или статичные дальние анимации;
- ползунок дальности полных анимаций от 0 до 256 блоков (`0` означает «Отключены»);
- настройка частоты кадров пониженных анимаций;
- уменьшение или отключение частиц Create;
- настройка дальности теней предметов на конвейерах;
- поиск причины лагов и замер производительности до/после прямо в игровом мире;
- определение активных шейдеров через публичный API Iris;
- полная русская и английская локализация интерфейса.
- переключатель **«Ускоренный рендер»** в разделе Flywheel. Он использует
  путь из CreateBetterFPS только при наличии одновременно Sodium и Iris.

Нажмите **G** в игровом мире, чтобы открыть компактное меню. Во время
диагностики мир продолжает работать, а игроку предлагается сохранять положение
и направление камеры.

## Сборка

В Windows:

```powershell
.\gradlew.bat clean test build
```

В Linux или macOS:

```bash
./gradlew clean test build
```

Готовый JAR появится в каталоге `build/libs/`.

Файл готового релиза называется
`Create-Give-Me-FPS-0.1.4-NeoForge-1.21.1.jar`.

## Важные ограничения

Настройки уменьшают частоту или останавливают поддерживаемые анимации. Они не
заменяют блоки Create специальными низкополигональными моделями или текстурами
меньшего разрешения. Успешная сборка также не гарантирует одинаковый прирост FPS
на каждом заводе и с каждым набором шейдеров. Сравнивайте производительность в
одном положении, с одинаковой камерой, разрешением, дальностью прорисовки и
настройками шейдеров.
